这是一个性别文化相关的整理，没有额外的分析内容。

### 父权的误解和误用

学术意义上的父权制，不等于“男性压迫女性”。它指的是一套以支配、刚强、等级为核心的性别规范体系，男性同样被它规训和伤害，所以一些所谓的女权主义者只批判父权制对女性的客体化，这个批判是不太公正的。

但这里就会产生一个问题，客体化压迫女性，这个压迫是显而易见的，那父权对男性的压迫是什么，总不能说学术上有那就是真有吧，我们现在来回答这个问题。

### 隐蔽的失语

让我们先看一个有趣的观察，我们说“女装”的时候，其实就是在表达男性穿女性服装这一种含义，因为女性穿女性服装不需要强调女这个字。我们说女装，多半带有笑料或者丑闻的含义。

那反过来呢，花木兰女扮男装，这是美谈。在语言学里，这种不对称有一个正式的名称叫标记性。

这样我们就可以整理出第一个光谱，关于服装审美和性别的：

```
女性美 ←————— 中性/实用 ————→ 男性美
(裙装、妆容)  (T恤、牛仔裤)    (缺失)
```

但这仍然没有回答最开始的问题，所以我们需要更进一步，是什么导致了这样的情况呢？

答案是现代服装符号系统是高度性别化的。装饰性被编码为女性特质。换句话来说，男性如果追求装饰，就会被解读为不够男性或女性化。（这个的发生是近代才有的，比如J.C. Flügel 的“男性大弃绝”）

所以我们谈论服装符号其实就是在谈论性别文化，那背后的东西是什么呢，答案是情感分工（功能主义家庭社会学用语，Talcott Parsons 和 Bales，1955）

在资本主义生产体系中，男性被期待提供工具性支持，而女性被期待提供情感性支持。

这种分工的后果是男性的情感需求被结构性压抑，柔软、脆弱、被照料的需求没有符合社会期望的出口，而所有的情感表达被外包给女性。社会奖励“强硬、竞争、控制情绪”的男性，惩罚“敏感、温柔、表达脆弱”的男性，以此来维持性别等级。

这就是男性所面对的另一个光谱：

```
柔软/脆弱 ←————— 中性 ————→ 刚强/坚忍
(禁区)            ✓             ✓
```

这是有代价的，女性抑郁症诊断率更高，而男性平均寿命更短，自杀完成率更高。乍一看可能觉得有些奇怪，这是正常的，同这个结构一样，后果也是隐蔽的。

### 共同的禁忌

女装这个事情其实离我们并不遥远，甚至可以说，我们绝大多数人某种意义上都在参与这个事情。想想自己有没有用过二次元美少女作头像，这两件事看起来没什么关系，但实际上是同一条光谱上的。

它们同属于“成为美”这种审美体验，与之相对的还有“欣赏美”，这是最基本的区分，看艺术家创作和自己创作当然是两种不同的体验，但前文已经说过，对于男性来说，成为是要受到惩罚的，有没有被自己的父母批评过头像不够阳刚，这就是比较轻微的惩罚。

所以这只是成本上的区别，物理的、社会的、心理的，各种意义上的，而女装只是一个高成本端。

### 借来的羽毛

但很明显，这终归是借来的东西，女装，无论指的是女性服装还是女性气质，都没法跟女解绑，这就是语言的暴力了，还是那个老问题，“我的语言的界限意味着我的世界的界限”，连缺少了什么其实都没法直说。

性别文化是一个相当大的问题，比如男人行动，女人显现；男人看女人，女人看自己被看。（John Berger《观看之道》）这只是一个例子，但也足够说明这是一个系统性的结构了，很难说有一个具体的解决方向，甚至很难说是一个问题。
