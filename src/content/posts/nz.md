## 引言：共同的禁忌

女装，一种逐渐走进大众视野的现象。从程序圈里图灵影响后代的讨论到广泛的小男娘，大众似乎对这种性别流动更加包容了，甚至会欣赏和赞美。

问起原因，除了禁忌感，他们大多会说是他们不仅仅想观看美，而是成为美。

但问题就来了，为什么成为美，需要女装？

我们的身边有无数使用女性ACG头像的男性朋友，VRChat里有大量选择女性形象的男性玩家，男性设计自己的非商业向vtuber形象时，也是女性形象占绝大多数。女装其实只是这条连续谱上成本最高的一环。如果把女装换成使用女性符号进行自我表达，那潜在人群的数量会非常大。

这种趋势本身并不正常。

## 一、符号的囚笼：男性美学的消失

### 1.1 消失的光谱

现在，请你列举出3种独属于男性的服装设计（体现男性美，女性穿不合适）。

列不出来是很正常的，我们可以轻易的列举出一大堆女性可穿但男性不可穿的服装，但反过来竟然完全行不通了。

所以关于服装审美和性别，我们可以列出一个光谱：

```
女性美 ←————— 中性/实用 ————→ 男性美
(裙装、妆容)   (T恤、牛仔裤)      (缺失)
```

这就回答了我们上面的问题，不是男性不能美，而是男性美的符号系统已经瓦解。今天的男性服装几乎全部聚焦于中性或者实用，比如：西装（职业化）、T恤牛仔裤（休闲化）、运动服（功能化）。没有一种服装是为了纯粹的美而存在。

相比之下，女性就自由多了：既可以选择裙装、妆容等女性美符号，也可以选择裤装、西装等中性符号，甚至可以刻意的追求帅气。

### 1.2 历史的断裂

在前现代社会，男性美其实有完整的符号系统：
- 中国：长袍、玉佩、折扇，"陌上人如玉，公子世无双"
- 欧洲：贵族的假发、花边、丝绸、高跟鞋
- 日本：装束、和服

这些符号明确标记的是"男性美"，而非中性或女性化。它们强调装饰，精致以及最重要的身份展示。但工业革命后，一切都变了。

### 1.3 现代性的规训

福柯在《规训与惩罚》中指出，现代社会通过规训生产有用的身体。对男性身体的规训尤其严苛，从早期的军事化规训（18-19世纪），工业化规训（19-20世纪），再到20世纪开始的消费社会性别分工，男性一直被分配功能性角色，而女性逐渐走向了展示性角色，这就导致了美学投资几乎全部往女性身体集中。

罗兰·巴特在《流行体系》中分析过：现代服装符号系统是高度性别化的。装饰性被编码为女性特质。换句话来说，男性如果追求装饰，就会被解读为不够男性或女性化。

结果就是今天的男性甚至没有词汇来描述我想要装饰性的、非功能的、纯粹为了美的自我呈现，因为这句话本身就会被理解成你想穿女装。

## 二、情感的分工：刚强的代价

### 2.1 另一个消失的光谱

抛开大女主一类病态的女性结构，现代社会其实是很支持强硬的女性角色的，比如职场上的女强人，但除了被社会鄙夷的0，你能想象软弱的男性角色吗？

这就是男性所面对的另一个光谱：

```
柔软/脆弱 ←————— 中性 ————→ 刚强/坚忍
(禁区)            ✓             ✓
```

这不是对称的。女性获得的是向上流动的权利，男性失去的是人性完整的权利。

### 2.2 情感劳动的分工

社会学家Arlie Hochschild在《情感劳动》中提出：现代社会存在情感分工。

在资本主义生产体系中，男性被期待提供工具性支持，而女性被期待提供情感性支持。

这种分工的后果是男性的情感需求被结构性压抑，柔软、脆弱、被照料的需求没有符合社会期望的出口，而所有的情感表达被外包给女性（妻子、母亲、女友）。

这里引用一个理论，R.W. Connell的支配性男性气质（hegemonic masculinity）
其揭示：社会通过奖励"强硬、竞争、控制情绪"的男性，惩罚"敏感、温柔、表达脆弱"的男性，来维持性别等级。

## 三、借来的羽毛：女装作为症候

### 3.1 为什么是女装？

回到开头的问题：为什么男性想要"成为美"，路径只能是女装？

现在我们得出了一个初步的答案：
1. 男性美学符号系统已经瓦解，装饰性、精致感、非功能美被全部编码为女性
2. 男性情感表达被严格规训，柔软、被看、被欣赏的权利被定义为女性特质
3. 如果男性想要这些体验，只能借用女性的符号系统

### 3.2 "欣赏美"与"成为美"

"不仅仅想观看美，而是成为美。"
这句话揭示了主体位置的转换：

- 欣赏美：我是观看的主体，美是外在客体
- 成为美：我是被看的主体/客体，我具身地体验美

长期以来，男性被固定在观看者的位置，这种单向凝视造成主体的贫乏。Lacan的镜像理论指出：主体需要通过他者的目光来确认自我。但男性的自我镜像是贫瘠的——除了"有用""强大""成功"，没有"美""精致""柔软"。

另一面镜子不言而喻。

### 3.3 越界的快感与困境

还记得我们开头说的除了禁忌感吗，其实除了我们都知道的反叛快感，还有脱离传统男性角色，美学解放，和角色更替（可以柔软、可以被看）三种深层作用。

但这种越界是有代价的：

一是这是个巨大的误读。社会无法理解"我只是想要装饰性和柔软，但我仍然是男性"这个表述。

二是身份认同的边界，如果你跟女装爱好者交流，他们一定会强调"我没有性别认同问题"。大多数人也会控制在特定场合，特定空间，特定情境里面。因为一旦变成日常，旁观者的看法就会从"玩cosplay"转向"他是不是要变性"。即使当事人反复解释我只是喜欢，社会也很难接受。

这是一种性别秩序的不对称。向下的越界被视为贬值，需要严重理由；向上的越界被视为升值，无需解释。

### 3.4 虚拟空间

这也解释了为什么无数男性使用女性ACG头像，VRChat中大量男性选择女性形象，游戏中男性更愿意捏女性角色。

女装只是这个连续谱上的高成本端。如果女装的成本（物理的、社会的、心理的）能降低到换头像的程度，实践者同样会暴增。

## 四、资本与父权的共谋

### 4.1 凝视经济

在消费社会，"被看"其实是一种经济资源。

John Berger在《观看之道》中指出两点：
- 男人行动，女人显现
- 男人看女人，女人看自己被看

这是一种经济结构，比如美妆产业主要面向女性，服装产业的多样性高度倾斜于女性，整形、医美、护肤的主要消费者也是女性。
女性被定义为"被看的性别"，美学投资成为必需品。男性则被定义为"看的性别"，美学投资被视为娘炮。

资本主义精准捕捉到这一点：女性身体是更好的利润来源，因为美学焦虑可以无限生产。

但这同时意味着男性美学市场萎缩的结构原因：资本没有动力去发展多样化的男性美学产品，因为男性规范降低了需求。

### 4.2 父权制悖论

女性主义批判父权制对女性的客体化。但这里有个悖论：

客体化压迫女性，但也给女性提供了一套丰富的美学符号和情感表达空间。女性可以装饰、可以柔软、可以被欣赏。

男性逃脱了客体化，但代价是美学和情感的全面贫困化。男性不被允许仅仅作为美而存在，必须时刻证明功能性和生产性。

这是父权制对不同性别的不同暴力。问题不在于谁更惨，而在于性别二元秩序本身就是个囚笼，只是囚禁的方式不同。

## 五、囚笠的自我维系

### 5.1 跨代复制

父母规训儿子"男孩不能哭""不能穿粉色"，不是恶意，而是焦虑——担心孩子因偏离规范而被惩罚。这种焦虑是理性的，因为规范的暴力是真实的。

于是形成了循环，更关键的是，整个教育体系都是如此。

### 5.2 经济依赖

资本主义劳动力市场需要特定的性别气质：男性必须"坚韧""不感情用事""以事业为重"。符合传统男性气质的人有系统性优势。

于是消费市场形成路径依赖，而打破这个循环需要巨大的先期投入和承受亏损的意愿，但在资本逻辑下，谁愿意做赔本买卖？

### 5.3 语言暴力

我们缺少词汇来描述"非二元的性别表达"。描述男性美学追求的词汇几乎都带性别标记，我们缺少中性的、丰富的美学词汇来描述男性的装饰性、柔软、精致。

当语言缺席，思想就被困住。

更深层的是：现代性别符号系统建立在严格的二元对立之上。每个符号都必须明确归属于一个性别。因为性别二元制是现代社会组织的基础，而这套系统需要可识别性。

所以社会对"跨性别符号使用"的暴力反应，本质是维护符号系统秩序的暴力。

### 5.4 男性等级

男性气质是等级化的金字塔，从上到下可以分成支配，共谋和从属，这个名称是不是很熟悉。

这个金字塔是通过羞辱底层来维系顶层的权力。

"娘炮"羞辱是权力工具：划定"真男人"边界，制造偏离规范的恐惧，转移自身的"不够男人"焦虑。

关键在于：大部分男性都感到"不够男人"。支配性男性气质的标准是故意设置为无法完全达到的，以维持永久的焦虑和竞争。

### 5.5 协调困境

这种政治动员，早期行动者承担最大代价，晚期参与者享受最大收益。
而且女装但不跨这个群体没有统一身份认同，高度分散，缺乏共同利益诉求，内部差异还大。

动员的结果不言而喻。

### 5.6 心理内化


一个从小被教育"男人不能哭"的人，到成年时不是想哭但忍住，而是真的哭不出来了。同样，一个从未被允许追求美的男性，不是想要美但不敢，而是真的感觉不到这种需求了。

福柯称之为主体化：权力不仅压迫主体，更生产主体。

当大多数男性说我不需要打扮，这可能意味着：真的不需要、需要但不自知、需要但否认。无论哪种，都很难被动员起来要求改变。

### 5.7 小结

看到这里，你应该明白了，这是一个自我强化的循环系统。 每个环节都在为其他环节提供正当性，没有单一的恶人，但系统性的暴力正在运转。
